# Κληρονομημένο υποσύστημα Agent Skills

Ο φάκελος `skills/` περιέχει παραδείγματα, προδιαγραφές και αρχεία `SKILL.md` από τη βάση του έργου. **Δεν αποτελεί κατάλογο επαληθευμένων λειτουργιών του Box Omni ή του GGUF backend.**

Στην τρέχουσα branch η διαδρομή `AgentChatTaskModule` καλεί απευθείας `LlmChatModelHelper` (LiteRT-LM). Δεν έχει πιστοποιηθεί ότι τα GGUF μοντέλα μπορούν να εκτελέσουν τις ίδιες κλήσεις εργαλείων. Τα επιμέρους `.md` των skills παραμένουν αμετάβλητα ως πηγές οδηγιών για το υπάρχον υποσύστημα.

Πριν δηλωθεί κάποιο skill υποστηριζόμενο πρέπει να ελεγχθούν: διαθεσιμότητα UI, σύνδεση runtime, άδειες Android, συμπεριφορά χωρίς δίκτυο, ασφάλεια εργαλείων και πραγματική εκτέλεση.

Η ανεξάρτητη ιστορική τεκμηρίωση του αρχικού υποσυστήματος βρίσκεται στο [Google AI Edge Gallery](https://github.com/google-ai-edge/gallery). Η τρέχουσα κατάσταση του fork καταγράφεται στο [docs/UI_BACKEND_AUDIT.md](../docs/UI_BACKEND_AUDIT.md).
