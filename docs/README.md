# Επίσημο αρχείο έργου Box Omni

**Κανόνας:** Τεκμηριώνουμε όσα υπάρχουν και αποδείχθηκαν στο **δικό μας repository**, όχι όσα υπόσχονται παλαιότερες εκδόσεις του Box ή άλλες εφαρμογές.

## Ενεργά έγγραφα

1. [PROJECT.md](PROJECT.md) — στόχοι, όρια, αποδεκτή αρχιτεκτονική.
2. [STATUS.md](STATUS.md) — τι λειτουργεί, τι έχει μόνο μεταγλωττιστεί, τι λείπει, ποια στοιχεία παραμένουν ανεπιβεβαίωτα.
3. [UI_BACKEND_AUDIT.md](UI_BACKEND_AUDIT.md) — πλήρης πίνακας UI, settings, engines, tasks και σφαλμάτων σύνδεσης.
4. [PLAN_NEXT_APK.md](PLAN_NEXT_APK.md) — ενιαίο σχέδιο πριν από την επόμενη δοκιμαστική έκδοση, με προϋπολογισμό ωρών και acceptance gates.
5. [RELEASE_PROTOCOL.md](RELEASE_PROTOCOL.md) — υποχρεωτικό checklist πριν και μετά από κάθε APK.
6. [CHANGELOG.md](CHANGELOG.md) — χρονολογημένες εργασίες, Git SHAs, CI, πραγματικές δοκιμές και αποτυχίες.
7. [DECISIONS.md](DECISIONS.md) — αρχιτεκτονικές αποφάσεις, αιτιολογήσεις, εναλλακτικές.
8. [UPSTREAM.md](UPSTREAM.md) — προέλευση, κληρονομημένες εξαρτήσεις και νομική αναφορά.
9. [DEVICE_TESTS.md](DEVICE_TESTS.md) — παρατηρήσεις από την πραγματική συσκευή και τι δεν αποδεικνύουν.

## Ιστορικά κείμενα

- [lfm3-omni-android-plan.md](lfm3-omni-android-plan.md): αρχικό σχέδιο, χρήσιμο για τον συλλογισμό και την ιστορική διαδρομή. Για ενεργό προγραμματισμό υπερισχύει το `PLAN_NEXT_APK.md` και για τρέχοντα αποτελέσματα το `STATUS.md`.

## Κανόνες καταγραφής

- Κάθε συνεδρία εργασίας καταγράφει ημερομηνία, σκοπό, συγκεκριμένα αρχεία, commits, ευρήματα, δοκιμές, αποτελέσματα και εκκρεμότητες.
- Όσα δεν έχουν δοκιμαστεί σημειώνονται **ΑΝΕΠΙΒΕΒΑΙΩΤΑ**. Τα build successes δεν ταυτίζονται με device successes.
- Καμία ένδειξη CPU/GPU/NPU δεν θεωρείται απόδειξη εκτέλεσης χωρίς runtime logs/profiling.
- Κανένα επόμενο APK χωρίς ενημερωμένο και πλήρες σχέδιο έκδοσης και κριτήρια αποδοχής.
- Δεν αφαιρούμε άδειες, notices, προέλευση τρίτων, ιστορικά Git commits ή αναγκαίες εξαρτήσεις στο όνομα της «εκκαθάρισης».
- Δεν αποκρύπτουμε λάθη: καταγράφονται μαζί με τη διόρθωση και τον τρόπο επαλήθευσης.
