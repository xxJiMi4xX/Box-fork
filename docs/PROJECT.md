# Box Omni — προδιαγραφή έργου

**Έκδοση εγγράφου:** 2026-11-03 · **Ενεργή branch:** `feature/gguf-v080-native` · **Μη μεταβλητό:** δεν αλλάζουμε `main` χωρίς ξεχωριστή απόφαση.

## Πρωταρχικός στόχος

Μία εφαρμογή Android που επιτρέπει offline λειτουργία με συμβατά GGUF και LiteRT-LM μοντέλα, όπου το UI αντανακλά το **πραγματικό** backend, τις υποστηριζόμενες δυνατότητες και τη δυνατότητα εκτέλεσης στη συγκεκριμένη συσκευή.

## Πεδίο

- GGUF: llama.cpp v0.8.0 σε ARM64, αρχικά σταθερή παραγωγή κειμένου, έπειτα `mtmd` για εικόνες/ήχο και εφόσον υποστηρίζεται παραγωγή φωνής.
- LiteRT-LM: διατήρηση της υφιστάμενης διαδρομής `.litertlm` χωρίς παλινδρομήσεις.
- Επιτάχυνση: CPU πάντα ως διαθέσιμη δοκιμή αναφοράς· GPU μόνο με πραγματική εκτέλεση και επαλήθευση· NPU μόνο με τεκμηριωμένο runtime/model compatibility και επαληθευμένη συσκευή.
- Ολοκληρωμένο import GGUF + matching `mmproj`: επιλογή, έλεγχος, αποθήκευση, φόρτωση, error handling, επαναφόρτωση.
- UI και settings: κάθε control πρέπει να έχει μία σαφή σημασιολογία και να αντιστοιχεί σε υποστηριζόμενη λειτουργία.
- Σταθερότητα: εκκίνηση, πολλαπλές συνομιλίες, ιστορικό, stop/reset, background/foreground, σφάλματα, διαχείριση μνήμης.
- Ιδιωτικότητα: σωστή παρουσίαση του offline mode, βιομετρικών, screenshots, permissions, μετανάστευσης βάσης.

## Ρητές απαγορεύσεις ισχυρισμών

- Όχι ισχυρισμός ότι CPU/GPU/NPU ελέγχονται από το UI όταν το backend αγνοεί την τιμή.
- Όχι ισχυρισμός ότι native βιβλιοθήκη NPU στο APK ή εμφάνιση ένδειξης «NPU» αποδεικνύει επιτάχυνση.
- Όχι ισχυρισμός περί υποστήριξης εικόνας/φωνής επειδή υπάρχει projector loader ή checkbox.
- Όχι υπόσχεση καθολικού offline blocking χωρίς επιθεώρηση όλων των δικτυακών κλήσεων.
- Όχι παρουσίαση κληρονομημένων feature lists ως επαληθευμένων χαρακτηριστικών του fork.
