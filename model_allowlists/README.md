# Κατάλογοι μοντέλων

Ο φάκελος περιλαμβάνει καταλόγους μοντέλων που κληρονομήθηκαν από το upstream. **Η παρουσία μοντέλου στον κατάλογο δεν αποδεικνύει ότι εκτελείται στο δικό μας fork ή στο Poco X6 Pro.**

Για μοντέλα GGUF, εικόνας και ήχου απαιτείται έλεγχος αρχιτεκτονικής, απαιτήσεων μνήμης, runtime backend και τυχόν συνοδευτικού `mmproj` πριν παρουσιαστούν ως λειτουργικά.

Βλ. [κατάσταση έργου](../docs/STATUS.md) και [πρωτόκολλο έκδοσης](../docs/RELEASE_PROTOCOL.md).
